# Начало работы: от скачанного ZIP до запущенной программы

Инструкция для первого раза. Делай строго по порядку, ничего не пропуская.
Если на каком-то шаге получилось не так, как написано — остановись и посмотри
раздел «Если что-то пошло не так» в конце.

---

## Часть 1. Куда распаковать архив

### Шаг 1.1. Скачай архив

На сайте открой ссылку `/downloads/AbizShell.zip` — браузер скачает файл
`AbizShell.zip` в папку «Загрузки».

### Шаг 1.2. Разблокируй архив

Это важный шаг, его часто пропускают. Windows помечает все файлы из интернета как
небезопасные, и Visual Studio потом откажется их собирать.

1. Найди `AbizShell.zip` в папке «Загрузки».
2. Нажми на него **правой кнопкой** → **Свойства**.
3. Внизу окна, если есть надпись «Этот файл получен с другого компьютера...» —
   поставь галочку **Разблокировать**.
4. Нажми **ОК**.

> Если такой надписи нет — ничего делать не нужно, файл уже разблокирован.

### Шаг 1.3. Распакуй в правильное место

**Не распаковывай в «Загрузки», на «Рабочий стол» или в «Документы».** Там длинные
пути с русскими буквами, из-за которых сборка может падать с ошибкой про
«слишком длинный путь».

Сделай так:

1. Открой «Этот компьютер» → диск **C:**
2. Создай там папку с именем **`Projects`** (английскими буквами).
3. Нажми на `AbizShell.zip` правой кнопкой → **Извлечь всё...**
4. В поле пути впиши вручную: `C:\Projects`
5. Нажми **Извлечь**.

Должно получиться вот так:

```
C:\Projects\
    AbizShell.sln              ← файл решения, его будем открывать
    README.md
    СБОРКА-ИНСТАЛЛЯТОРА.md
    НАЧАЛО-РАБОТЫ-VS2026.md    ← этот файл
    build-installer.ps1
    AbizShell\
        AbizShell.csproj
        MainWindow.xaml
        ... (остальные файлы программы)
    installer\
        Product.wxs
        redist\
```

Проверь, что файл `AbizShell.sln` лежит прямо в `C:\Projects`, а не в
`C:\Projects\AbizShell\AbizShell.sln`. Если архив распаковался с лишней вложенной
папкой — просто перенеси содержимое на уровень выше.

## Часть 2. Что установить в Visual Studio 2026

### Шаг 2.1. Открой Visual Studio Installer

Нажми **Пуск** → начни печатать `Visual Studio Installer` → открой его.

Увидишь список установленных версий студии. У **Visual Studio 2026** нажми
кнопку **Изменить**.

### Шаг 2.2. Поставь галочку на рабочую нагрузку

Откроется окно с плитками. Тебе нужна **одна** плитка:

| Плитка | Название |
|---|---|
| ✅ | **Разработка классических приложений .NET** |

В английской версии она называется *.NET desktop development*. Найди её в разделе
«Классические приложения и мобильные приложения» и поставь галочку.

> Эта плитка весит около 6 ГБ и включает всё нужное: компилятор C#, конструктор
> окон WPF, отладчик.

### Шаг 2.3. Проверь отдельные компоненты

Переключись на вкладку **Отдельные компоненты** (сверху) и через поиск убедись,
что отмечены:

- ✅ **.NET 8.0 Runtime (Long Term Support)**
- ✅ **Пакет SDK для .NET 8.0**

Если их нет в списке отмеченных — отметь вручную.

### Шаг 2.4. Запусти установку

Внизу справа нажми **Изменить**. Установка займёт 15–40 минут в зависимости
от скорости интернета. Можно пока читать дальше.

## Часть 3. Первый запуск программы

### Шаг 3.1. Открой решение

Зайди в `C:\Projects` и **дважды щёлкни по файлу `AbizShell.sln`**.

Откроется Visual Studio 2026. Справа в окне **Обозреватель решений** увидишь три
проекта:

```
Решение "AbizShell" (3 проекта)
├── AbizShell          ← сама программа
├── AbizInstaller      ← сборка MSI (понадобится позже)
└── AbizBundle         ← сборка .exe (понадобится позже)
```

> **Если проекты AbizInstaller и AbizBundle помечены как «несовместимые»** — это
> нормально, для них нужно расширение WiX. Оно понадобится только когда будешь
> собирать установщик, см. `СБОРКА-ИНСТАЛЛЯТОРА.md`. Сейчас на это не обращай
> внимания, программа соберётся и без них.

### Шаг 3.2. Подтяни пакеты (библиотеки)

Программе нужны готовые библиотеки из интернета — браузерный движок и несколько
вспомогательных. Студия скачает их сама.

1. В **Обозревателе решений** нажми правой кнопкой по строке
   **Решение "AbizShell"** (самая верхняя).
2. Выбери **Восстановить пакеты NuGet**.
3. Внизу в окне **Вывод** побегут строки. Дождись надписи
   *«Восстановление выполнено»* / *«Restore completed»*.

Это занимает 1–3 минуты при первом разе. Что именно скачивается:

| Пакет | Для чего нужен |
|---|---|
| `Microsoft.Web.WebView2` | Встроенный браузер, в котором открывается сайт |
| `System.Management` | Чтение данных о компьютере |
| `System.Text.Json` | Обмен данными с сервером |
| `Newtonsoft.Json` | Работа с настройками |
| `Serilog` | Запись журнала работы |
| `Microsoft.Extensions.DependencyInjection` | Внутренняя организация кода |

> Отдельно их устанавливать **не нужно** — они уже прописаны в проекте, студия
> просто скачивает их по списку.

### Шаг 3.3. Выбери правильную конфигурацию

Наверху, на панели инструментов, есть два выпадающих списка. Выставь их так:

- Первый: **Debug** (для запуска с отладкой)
- Второй: **x64**

### Шаг 3.4. Собери программу

Меню **Сборка** → **Собрать решение** (или клавиша **F6**).

Внизу в окне **Вывод** должно появиться:

```
Сборка: успешно 1, не пройдено 0
```

> Если проектов установщика нет в студии, то «успешно 1» — это правильно,
> собрался сам `AbizShell`.

### Шаг 3.5. Запусти

Нажми **F5** (или зелёный треугольник ▶ с надписью **AbizShell** наверху).

**Windows покажет запрос прав администратора** — нажми **Да**. Так и должно быть:
программе нужны права, чтобы блокировать системные клавиши.

Через 2–5 секунд откроется чёрный экран на весь монитор с надписью **АБИЗ** и
полем для пароля.

### Шаг 3.6. Как выйти из программы при отладке

Программа специально сделана так, что её сложно закрыть. Чтобы выйти во время
разработки:

- **Способ 1 (главный):** вернись в Visual Studio (`Alt+Tab` может не работать —
  тогда нажми `Ctrl+Alt+Del` → Диспетчер задач) и нажми в студии красный
  квадрат ⏹ **Остановить отладку** (или `Shift+F5`).
- **Способ 2:** введи пароль администратора `832605633`, затем нажми шестерёнку
  в правом верхнем углу → **Выйти в Windows**.

> Пароль сотрудника — `243063`. Но без привязки устройства он не пустит,
> это защита. При отладке пользуйся паролем администратора.

## Если что-то пошло не так

**«Проект несовместим» у AbizInstaller / AbizBundle**
Нужно расширение WiX. Для запуска самой программы оно не требуется — просто
работай с проектом `AbizShell`. Установка WiX описана в `СБОРКА-ИНСТАЛЛЯТОРА.md`,
часть 1.2.

**Ошибка «Не удалось найти пакет Microsoft.Web.WebView2»**
Не прошло восстановление пакетов. Проверь интернет и повтори Шаг 3.2.
Если не помогает: меню **Инструменты → Диспетчер пакетов NuGet → Параметры
диспетчера пакетов** → раздел **Источники пакетов** → убедись, что включён
источник `nuget.org`.

**Ошибка «Путь слишком длинный» (The specified path is too long)**
Архив распакован слишком глубоко. Перенеси папку прямо в `C:\Projects`, как
написано в Шаге 1.3.

**Программа запустилась, но окно сайта белое или пустое**
Не установлен движок браузера WebView2. Скачай и установи «Evergreen Bootstrapper»
отсюда: `https://developer.microsoft.com/microsoft-edge/webview2/`
На Windows 11 он обычно уже есть.

**При запуске (F5) каждый раз появляется запрос прав администратора**
Так задумано, этого требует файл `app.manifest`. Если при разработке это мешает,
можно временно отключить: открой `AbizShell.csproj` двойным кликом по названию
проекта и закомментируй строку
`<ApplicationManifest>app.manifest</ApplicationManifest>`, обернув её в `<!-- -->`.
**Перед сборкой установщика верни её обратно** — без прав администратора защита
киоска не работает.

**Программа заняла весь экран, не могу вернуться в студию**
Нажми `Ctrl+Alt+Del` → **Диспетчер задач** → найди `AbizShell` → **Снять задачу**.
Это системная комбинация, её программа перехватить не может.

**«Сборка: не пройдено 1» с красными ошибками в окне «Список ошибок»**
Скопируй текст первой ошибки целиком и пришли мне — разберу и поправлю код.
