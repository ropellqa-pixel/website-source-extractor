# АБИЗ Shell — проект Visual Studio 2026 (.NET 8, WPF)

## Новое в версии 14

- **Кнопка «Камера Зал»** на экране ввода пароля — прямая трансляция камеры «Зал-Касса»
  (только живое видео, без архива). Внизу длинная кнопка **«ВХОД — Авторизация»** —
  возвращает на экран пароля. Если связь с камерой пропала, программа переподключается сама.
- **Встроенный видеодекодер VLC** (бесплатный) — камеры в формате H.265 показываются
  без платного «Расширения для видео HEVC» из Microsoft Store. Устанавливать ничего не нужно.
- **Верхняя панель: «Сеть» и «Громкость».** Сеть — состояние подключения, IP-адреса, кнопки
  «Wi‑Fi сети», «Параметры сети», «Проверить связь», для администратора — «Сетевые адаптеры».
  Громкость — ползунок, кнопки 0/25/50/75/100 %, выключение звука.
- **АБИЗ-Админ** — вторая программа из того же кода: обычное окно Windows (рамка, свернуть,
  закрыть), без автозапуска, без скрытия панели задач и без блокировки клавиш.
  В Visual Studio выбери конфигурацию **ReleaseAdmin** (или DebugAdmin) — получится `AbizAdmin.exe`.
  Установщик: `installer\out\AbizAdminSetup.msi` (собирается тем же `build-installer.ps1`).

## Как открыть

Если делаешь это впервые — открой **`НАЧАЛО-РАБОТЫ-VS2026.md`**. Там по шагам:
куда распаковать архив, что поставить в Visual Studio, как подтянуть пакеты и запустить.

Коротко:

1. Распакуй ZIP в `C:\Projects` (не в «Загрузки» — длинные пути ломают сборку).
2. Открой двойным кликом `AbizShell.sln`.
3. Правой кнопкой по решению → **Восстановить пакеты NuGet**.
4. Конфигурация **Debug** + **x64**, затем **F5**.
5. Выход из запущенной программы: пароль админа `832605633` → шестерёнка → «Выйти в Windows»,
   либо в студии `Shift+F5` (Остановить отладку).

## Что было исправлено по сравнению с присланным кодом

1. **Код не компилировался.** `DeviceManager.InitializeDeviceAsync()` создавал
   `new AnodBizClient()` без аргументов и вызывал на нём `RegisterDeviceAsync`/
   `CheckDeviceStatusAsync` — но в `AnodBizClient` единственный конструктор требовал
   `string apiToken`, а сами методы были объявлены `static`. Теперь `DeviceManager`
   вызывает `AnodBizClient.RegisterDeviceAsync(...)` напрямую через имя класса, без
   создания экземпляра — так и задумано: до привязки устройства токена ещё нет.
2. **Дубль стиля `EndWorkBtn` в XAML** — WPF падал с ошибкой «ключ уже существует
   в словаре ресурсов». Второй стиль переименован в `ShutdownBtnStyle`.
3. **Стиль `AppTile` не существовал**, хотя кнопки-плитки на него ссылались —
   падение `XamlParseException` при открытии меню. Стиль добавлен: закруглённый
   квадрат с тенью и лёгким увеличением при наведении (в духе macOS Launchpad).
4. **Мигание при открытии меню кнопок.** Раньше `OverlayApp_Click`/`ToggleOverlay`
   скрывали сам `MainBrowser` (`Visibility.Collapsed`) и меняли его `Margin` —
   это и давало "мигание" и могло на миг открыть системный рабочий стол. Теперь
   браузер и обе панели (верхняя и нижняя) **никогда** не скрываются и не меняют
   размер — переключается только видимость полупрозрачного `OverlayGrid` поверх
   них, через `Panel.ZIndex`.
5. **Tab/2×Space не всегда срабатывали.** Причина — `KeyInterop.KeyFromVirtualKey`
   в хуке иногда не совпадал с ожидаемым `Key` на нестандартных раскладках.
   Хук теперь сравнивает «сырые» virtual-key коды (`VK_TAB`, `VK_SPACE`) напрямую.
6. **Нижняя панель (блокировка/выключение/язык/проводник) добавлена отдельно** —
   раньше этих кнопок внизу по центру не было вообще, хотя этого требовал сценарий.
   Она закреплена `Panel.ZIndex="50"` и не участвует в скрытии/показе оверлеев.
7. **Печать.** Было: заготовка класса `PrintService` под `FixedDocument`, который
   никак не был связан с браузером — печатать было физически нечего. Теперь
   печать идёт через встроенный движок WebView2 (`CoreWebView2.ShowPrintUI`) —
   тот же диалог, что в Chrome/Edge: выбор принтера, копии, диапазон, ориентация.
8. **Кнопки теперь редактируются админом и хранятся на сервере**, а не только в
   памяти: `KioskButtonsService` читает/пишет таблицу `kiosk_buttons` через
   `data-api` (см. `API.md`, раздел про `kiosk_buttons`). При сохранении — весь
   список удаляется и вставляется заново с новым порядком, чтобы все ПК сотрудников
   подтянули одинаковый порядок при следующем запуске.
9. **Автовход** — без изменений по логике (она была верной): программа запрашивает
   одноразовый код по токену устройства и сама открывает браузер на
   `anod.saou.ru/device-login?code=...`; токен в URL никогда не передаётся.
10. **Проводник и выход в Windows** теперь явно доступны только администратору
    (проверка `IsAdmin`) — обычный пользователь не может их вызвать даже из UI.

## Сборка инсталлятора и установка на ПК сотрудников

Полная пошаговая инструкция — в файле **`СБОРКА-ИНСТАЛЛЯТОРА.md`** рядом с этим README.
Там расписано: что установить один раз, три команды сборки, раздача на ПК вручную
и через групповые политики, чек-лист проверки и разбор типовых ошибок.

Коротко: положи два файла в `installer/redist` (см. инструкцию, раздел 1.3) и запусти

```
powershell -ExecutionPolicy Bypass -File build-installer.ps1
```

Результат — `installer\out\AbizSetup.exe`, один файл для раздачи сотрудникам.
Первый запуск на ПК покажет 9-значный код устройства, который директор вводит на сайте:
**Сотрудники → Устройства → Привязать**.

## Известные ограничения, о которых стоит знать

- Полная блокировка «выхода из грани» Windows (Ctrl+Alt+Del, диспетчер задач) штатными
  средствами WPF невозможна — это системные комбинации, которые перехватывает сама ОС
  до любого приложения. Для киоска с такими требованиями обычно используют встроенный
  **Windows Kiosk Mode / Assigned Access** (через групповые политики) поверх этой
  программы — могу подсказать настройку, если понадобится.
- Собственный браузер с расширениями из Яндекс Браузера: WebView2 (движок Chromium)
  технически поддерживает Chromium-расширения через `AddBrowserExtensionAsync` (режим
  Dev), но массово ставить расширения из Яндекс Браузера нельзя — у них нет
  публичного стора в формате Chrome. Нужны конкретные `.crx`/распакованные папки
  расширений, которые ты хочешь использовать — пришли их, и я добавлю загрузку.
